# projr: Facilitate Reproducible and Archived Projects

Run R scripts and render 'Quarto', 'R Markdown' and 'bookdown' documents
in a configured order. Record file hashes for each version of an
analysis, archive its inputs and outputs locally or in 'GitHub'
releases, and restore the inputs for a checked-out version.
